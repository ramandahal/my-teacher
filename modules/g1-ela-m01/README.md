# G1-ELA-M01 — Sound Safari 🦁

Grade 1 English, chapter 1. Runs on the shared player (`../engine/`). No server, account, API or network needed.

| 5 | Spell short words (missing vowel) | RF.1.3b | 16 |

Design notes
- Wrong answers are chosen on purpose: e.g. for "starts like *sun*", one choice is *bus* (ends with s) so the feedback can teach "beginning vs end". In reading, wrong pictures differ by one sound (dog / log / duck).
- The voice reads every prompt and, for listening skills, the choices. Reading skills show pictures only, without words or voice, so the child really reads.
- Isolated letter sounds are not spoken (browser voices pronounce them badly); the voice uses whole words and anchor words (apple, egg, it, octopus, umbrella).
